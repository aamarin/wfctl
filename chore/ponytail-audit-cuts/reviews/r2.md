`(.*)$` stops before the trailing `\n`, and `.strip()` disposes of the `\r`, so
`"```\r\n"` still reads as a valid closer.

net: −7 lines possible in code (the duplicate `_io` test, the marker's audit
sentence); the ledger file itself is −86 if it moves out of the repo.
