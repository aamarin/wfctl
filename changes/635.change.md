`wfctl arch none` and `wfctl step none` now write their exception into the branch's spec folder, under `exceptions/`, instead of committing a file under the architecture folder. The reviewer reads the reason in the PR body, and `wfctl check-body` reports any exception whose reason the body is missing. Before a PR opens or merges, the worktree guard now also blocks it when the branch changes a level-2 record nobody has accepted, or one that contradicts the branch's own "no new boundary". An older wfctl still writes under the architecture folder, and those files no longer count, so upgrade wfctl before writing an exception.
