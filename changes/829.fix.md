An agent running `/speckit.brainstorm` now invokes `idea-refine` itself, instead of stopping until you type `/idea-refine`. With `auto_approve` on, it answers `idea-refine`'s questions from the approved design and writes `design.md` in the same turn. With it off, it asks before saving. Typing `/idea-refine` still works. Claude Code can also start `idea-refine` on its own when you say something like "ideate" or "stress-test my plan", and outside an unattended brainstorm it asks before it saves anything. `idea-refine` now installs with the ideation frameworks, evaluation rubric, examples, and helper script it tells the agent to use, which weren't shipped before. In an existing project, run `wfctl install-skills --agent claude --prune` to remove the old `/idea-refine` command.
