A worktree removal now saves a file listed in `save_on_remove`, which it used to delete without a word. A listed folder that holds the spec folder, such as `specs/`, is now saved too, apart from the spec folder, which is already saved on its own. A listed link to a file now saves the file as well as the link. A listed link to a folder is saved as a link, with the folder saved at its own path instead of under the link's name.
