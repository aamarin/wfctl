wfctl now ships two security reviews and a `reviewing-security` skill that tells a reviewer how to run them together. The `security-and-hardening` skill comes from addyosmani/agent-skills, with its hardening patterns and security checklist. The `/security-review` prompt from anthropics/claude-code-security-review ships as a reference inside `reviewing-security`, so it doesn't collide with Claude Code's built-in `/security-review` command. `NOTICES.md` credits both. No other skill calls `reviewing-security` yet, so this release doesn't change how a review runs. `security-and-hardening` installs under `.agents/skills/`, so an agent that finds skills there by description, such as Codex, can load it during ordinary work. That agent can't follow the skill's own path to the security checklist, which ships at `security-and-hardening/references/security-checklist.md`.
