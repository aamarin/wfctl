wfctl now ships two security reviews, and a `reviewing-security` skill that tells a reviewer how to run them together. The `security-and-hardening` skill comes from addyosmani/agent-skills, with its hardening patterns and security checklist. The `/security-review` prompt from anthropics/claude-code-security-review ships as a reference inside `reviewing-security`, so it doesn't collide with Claude Code's built-in `/security-review` command. Both are credited in `NOTICES.md`. No other skill calls `reviewing-security` yet, so installing this release changes nothing about how a review runs. `security-and-hardening` is installed under `.agents/skills/`, so an agent that finds skills there by their description, such as Codex, can now load it during ordinary work.
