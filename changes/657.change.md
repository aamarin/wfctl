In a repo whose domain page lists its contexts, brainstorm's software design check now pauses until each context a branch lists has a level-3 record that governs it, or a per-context "no" given with `wfctl step none brainstorm.software-design --context`. A level-2 record doesn't answer this check. A branch that passes the software design check today can pause after this ships. This also closes the gap from the architecture check's release: the software design pass can be skipped again in these repos, one context at a time.
