`wfctl auto-approve on` and `wfctl auto-approve off` turn auto-approve on or off at any point in a session. `wfctl auto-approve` with no argument prints the mode and whether this session, another session, or an unknown session turned it on.

A worktree created with `WFCTL_AUTO_APPROVE=1 workmux add` starts with the mode on, through a new `post_create` line in the `.workmux.yaml` wfctl ships. If your repository's `.workmux.yaml` predates it, `wfctl auto-approve` prints the line to add.

In Claude Code, `install-skills --agent claude` adds four `permissions.ask` rules, so Claude Code asks you before the agent turns the mode on.

In Codex, `install-skills --agent codex` now adds `.codex/rules/wfctl.rules`, so Codex asks you the same way. Codex loads that file only in a project you've trusted, and only when it starts, so restart Codex after installing.
