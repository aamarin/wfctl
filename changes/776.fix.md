The SVG edge warning now reads a label's font size and anchor the way a browser does. On each element an inline style wins over a class rule and a class rule wins over an attribute, `!important` raises a value above the others on its element, and of two class rules the later one wins. The nearest element that sets the value wins, and an `em` or `%` size scales its parent's size. Labels styled inline are no longer flagged when they fit, and a label sized by a group's class is measured at the size it renders at.
