An architecture record can draw its Boundary as an SVG file in `drawings/` under the arch root, linked as a markdown image, instead of a mermaid block. `wfctl arch accept` refuses a link that points at a missing file, a file outside `drawings/`, or a file it cannot read, and `wfctl doctor` warns about each while the record is proposed. wfctl reads the labels in the SVG and applies the same checks it applies to a mermaid drawing. A sequence SVG marks the step that fails with `class="failing-step"`, and doctor warns when a label runs past the drawing's edge. A record with a mermaid block is checked exactly as before.
