The worktree guard now blocks `gh pr create` and `gh pr merge` while any review group has commits it hasn't reviewed, and lists those commits under each group. To get past it, run the review groups with `wfctl review start` and `wfctl review check`, or have a person run `wfctl review sign-off` in their own terminal. The guard blocks that command when an agent runs it. The new `wfctl review groups` command lists the groups in the order they run. The `opening-a-change` skill now runs the security group before the code group on every change, and `fanning-out-code-review` runs each group through wfctl's review commands.
