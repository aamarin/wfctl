The worktree guard no longer refuses a command that only prints a person-only command as text or writes it to a file. That covers a quoted string that `echo` or `printf` prints, and a quoted heredoc that `cat` writes to a file, such as `cat > notes.md <<'EOF'`. If you add a pipe, a redirect, a second command, or a substitution, the guard still refuses it.

If you run `wfctl arch accept` on an accepted record whose last `Log` line is an amendment, it now writes a new `accepted` line, which records that you agreed to the amendment. Before, it reported the record as already accepted and wrote nothing. An accepted record with no later amendment still says so and writes nothing.
