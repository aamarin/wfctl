`wfctl arch context` now ends with a Views block listing the architecture views every repository needs: a system context view, a container view, and one component view for each context on the domain page. A missing view gets its own line, and a view whose covered code has commits newer than the view is marked stale. Neither blocks anything. wfctl ships a template for each view, and the domain model template now uses short lists instead of most of its wide tables.
