`wfctl arch context` prints only the accepted records that apply to the contexts a branch lists in its `design.md`, plus every record with no `governs` field, and says how many it left out. The session report's `Records` line gives the same two counts, and `wfctl status --session --json` adds `applying_records`. When the branch lists no contexts, or names one that isn't on the domain page, every record prints, and `wfctl arch context --all` prints every record on any branch.
