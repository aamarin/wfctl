A record's drawing link is now read the way GitHub reads it. A reference-style image such as `![flow][ref]` resolves to its definition. If the definition is missing and nothing else is drawn, the record gets a problem line naming the label instead of "no drawing". An image after an escaped backslash, `\\![x](…)`, counts as the drawing, and a protocol-relative link such as `//example.com/x.svg` is ignored like any other URL.
