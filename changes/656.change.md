In a repo whose domain page lists its contexts, brainstorm's architecture check now pauses until each context a branch lists has a level-2 record that governs it, or a per-context "no" given with `wfctl arch none --context`. A branch that passes the architecture check today can pause after this ships. In these repos, `wfctl arch none` and `wfctl step none brainstorm.software-design` are refused without `--context`. The software design check doesn't read a per-context "no" yet, so that pass can't be skipped in these repos until a follow-up lands.
