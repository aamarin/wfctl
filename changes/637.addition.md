wfctl now records which commits each review group covered. `wfctl review start <group>` writes a run record listing the expected reviewers and the commits since that group's last review, and `wfctl review check <group>` reads each reviewer's report, prints the roster, and moves the group's last reviewed commit forward once every report names the newest commit and ends with a verdict. `wfctl relay` saves the report of a reviewer that was blocked from writing it, marked as relayed with the reason. The new `review` key in `wfctl.json` adds other models and custom review groups, and `wfctl check config` reports a bad declaration.
