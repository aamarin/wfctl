wfctl now stores the spec files of a branch for you. `wfctl store specs` commits that spec folder in the spec store and pushes it, and `wfctl check specs` lists every spec dir that is not stored yet. The implement step ends with a store-specs pass, and removing a worktree stores its spec dir first, going ahead with a warning when the push fails. Removal no longer calls an uncommitted spec dir durable.
