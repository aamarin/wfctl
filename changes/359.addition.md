wfctl now automatically stores spec files for each branch. Previously, these files could remain uncommitted for extended periods. The `wfctl store specs` command commits and pushes a branch's spec files to a separate spec store in a different git checkout. The `wfctl check specs` command lists branches with unstored spec files. The implement step now concludes by storing specs. When removing a worktree, wfctl stores specs first and issues a warning only if the push fails. Uncommitted spec files are no longer marked as "durable" when a worktree is removed.
