Accepting a record now signs off its SVG drawing. The accepted line in the record's Log ends with each SVG's fingerprint, and wfctl doctor warns when an accepted record's SVG changes afterward. To sign off a layout fix, run wfctl arch accept on the record again, which adds a redrawn line and clears the warning. A branch whose only change to a record is a redrawn line doesn't count as moving a boundary. wfctl arch accept now refuses to write unless a person runs it at a terminal, and the worktree guard refuses it from an agent unless it carries --dry-run.
