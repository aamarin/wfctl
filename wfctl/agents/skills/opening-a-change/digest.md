SKILL.md governs; these break first.
1. Run the review panel first, on every change — in an unattended run nobody
   says "review this".
2. Its disposition table goes in the body. A body without one is what a skipped
   panel looks like.
3. Read the repo's template before writing a line. Every section, in its order;
   "N/A" over deletion, and Review Panel takes no "N/A".
4. `--body-file`, never `--body`.
5. An open PR is not done: sidebar, reviewers, `Closes #N`.
