WARNING  wfctl/agents/skills/reviewing-security/SKILL.md:L30-L57 — The skill keeps its own copy of the rule for which commits a run covers. It also takes a trunk input that the sibling contract gives the launcher no way to get.

  - The skill restates the rule with one `--not origin/main`. A local `main` ahead of `origin/main` that the branch merged would be excluded by wfctl but reviewed here. That is the two-homes drift `knowledge-placement` warns about, already present before #637 exists.

  - → Pick one place for this. Preferred: #637's `review start` prints the run's commit shas (it already computes them for the count), and this skill reviews exactly those with `git show <sha>` / `git log --no-walk -p <sha>…`, dropping the trunk input and the `--not` explanation.
  - At minimum, amend `contracts/cli.md` so `review start` prints the trunk refs (plural) and the skill accepts more than one.
