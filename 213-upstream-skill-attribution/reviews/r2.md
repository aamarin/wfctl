WARNING `tests/test_skill_attribution.py:L3` (and repeated at `L60`) — the docstring claims
"Six superpowers-derived skills shipped in the wheel for eleven releases with no copyright
notice." This is checkable against git history and is wrong: all six files trace to a single
origin, commit `8cadcdb` ("[43] Vendor the wf-skills tree into the wfctl package (#47)",
2026-08-17). `git tag --contains 8cadcdb` returns exactly `v0.15.0`, `v0.16.0`, `v0.17.0` — three
tagged releases, not eleven, shipped these files before this fix (`v0.14.0`, tagged 2026-08-11,
predates the vendoring commit and does not contain it). The issue text itself never states a
release count — "eleven" appears to be invented. This overstates the exposure by roughly 4x in
a file whose own stated purpose is to be trustworthy about why the test exists. → Fix: replace
"eleven releases" (both occurrences) with the correct count ("three releases") or drop the
specific number and say "every release since #47" as the issue itself does.
