WARNING  wfctl/_pipeline.py:L275-283 — `_tasks_open` checks the `implement-complete.md` sentinel *before* the empty-tally fallback, so a checkbox-free `tasks.md` plus that sentinel reads `implement: done` (no annotation) while `tasks` reads `in_progress` ("tasks.md holds no task") one row above it. ```
