### NIT — `SKILL.md:L249`: substring collision in the case pattern

`case " r1 r2 r3 " in *" $id "*` matches the *id* as a pattern against the roster
string, so an id that spans a roster boundary is accepted: a file named
`r1 r2.md` prints nothing. Verified. (I also checked the metacharacter case and
it is safe — the expansion is inside double quotes, so `r*.md` is matched
literally and correctly flagged, in both `sh` and `zsh`.) Filenames with spaces
are unlikely; the alternation form removes the question. → `case "$id" in r1|r2|r3)`.
*Fixed in the uncommitted tree.*
