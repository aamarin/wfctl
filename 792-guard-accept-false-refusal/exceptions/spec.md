# `spec` does not apply

Eleven security rounds each found a new way to hide the literal command, so the guard refuses the words wherever they appear. The rest is a fix: the guard stops refusing commands that only name wfctl, and closes literal forms the guard-catches-literal-accept record already requires it to refuse. No significant design decision beyond that record, which states the rule this enforces. No ownership change: the guard still makes the same decision from the same input.
