## Findings

**WARNING  wfctl/cli.py:2366 and wfctl/cli.py:2408 — two comments inside
`_MIRRORED_SKILLS` now assert a premise this commit made false.**
L2366–2367, on the `architecture-design` entry: "Same case as
`software-design-decisions` below — *no wrapper under `agents/commands/`* — but
it earns the entry for `start-session`'s reason rather than #124's."
L2408, on the `software-design-decisions` entry: "*No wrapper under
`agents/commands/`*, so the mirror is the only route: a skill absent from both is
reachable only by an agent already reading `design-levels` as text…"
Both wrappers now ship. The commit message's "`_MIRRORED_SKILLS` and
`_mirror_supersedes_wrapper` are untouched" is true of the code and not of the
rationale attached to it, and in this repo that rationale is the thing a reader
consults before deciding an entry is still earned — the commit itself says
dropping either name "would un-suppress its wrapper on claude and stop
`design-levels` §4's pointer resolving, which is #150 restored." A false premise
sitting on that decision has a live failure path. This is also the same class of
staleness the commit went out of its way to fix in the record's Context and in
two test docstrings; these two were missed.
→ Fix: amend both to say the wrapper ships since #373 and is suppressed on the
mirroring layer, so the mirror is still the only route *here* — the entry's
justification survives intact, only its stated premise changes.

**WARNING  tests/test_skill_cross_references.py:436 —
`test_the_design_record_skill_is_model_invocable` is now one membership
assertion, and its own sibling documents why that under-proves the name.**
`test_the_design_method_skill_is_model_invocable` (L137) kept two assertions and
says exactly why: "Membership alone does not settle it, and the name of this test
is the claim that overreaches if it stands alone … `disable-model-invocation` on
this SKILL.md would refuse the skill on the discovery path membership just put it
on, leaving no route at all … the key is a plausible copy-paste from any of the
wrappers carrying it." This commit just created
`wfctl/agents/commands/software-design-decisions.md` carrying that key, one
directory from the SKILL.md — so it raised the probability of the copy-paste the
sibling names, while reducing the test guarding the same claim to a single
assertion. The gap is pre-existing (the dropped assertion was never the
invocability check), but the asymmetry only became visible now and this is the
commit that created the copy-paste source.
→ Fix: mirror the sibling —
`assert "disable-model-invocation" not in _arch._frontmatter((_AGENTS / "skills" / "software-design-decisions" / "SKILL.md").read_text())`
— and restore a "Both assertions" line to the docstring.

**WARNING  tests/test_install_skills.py:290 — `_SUPPRESSED_ON_A_MIRRORING_LAYER`
grew from eight names to fourteen, and still nothing fails when it drifts.**
Its comment claims "the intersection is exactly the thing that has to be noticed
when it changes," but the only test reading it
(`test_every_suppressed_wrapper_still_ships_in_the_bundle`, L308) asserts
`pinned <= _MIRRORED_SKILLS` and that each pinned name has a wrapper. Adding a
wrapper for a mirrored skill and forgetting the pin stays green — which is
precisely what this commit did six times, correctly, by hand. The pin is now 14
of 15, so the manual surface is at its maximum and the next addition has the
smallest margin for noticing.
→ Fix, keeping the pin (this is the pin *checking* the derivation, not a test
reading its own subject):
`assert _SUPPRESSED_ON_A_MIRRORING_LAYER == {n for n in _MIRRORED_SKILLS if (agents / "commands" / f"{n}.md").exists()}`

**NIT  tests/test_skill_cross_references.py:139 (and the commit message) — "a
typed route on `.agents/` and bob" is one layer wider than the code.**
`_AGENT_TARGETS` gives a command path to claude (where these six are suppressed)
and bob; copilot gets skills only; codex — the one agent `_AGENT_NOTICES`
documents as reading `.agents/` directly — resolves to `[]` with "Codex has no
repo-local command path." `.agents/commands/` is the agent-agnostic base copy
(README:127, `layer-model`), not a discovery path anything types today. The
change is still right and the wrapper still has to ship to base for bob's copy to
exist; the claim is just broader than what it buys.
→ Fix: "a typed route on bob, and a pointer file on the base layer for whatever
reads it."

**NIT  tests/test_install_skills.py:319 — the reflow dropped the anchor that
dated the measurement.** "Deleting five of these seven leaves the suite at 838
passed" → "Deleting five of them left the suite at 838 passed". "them" now
denotes fourteen names, and 838 is a count from a suite that reports 1598 today,
so a reader who checks the number finds it wrong with nothing saying which era it
belongs to. The tense fix was right; the count carried the date.
→ Fix: "Deleting five of the seven that existed then left the suite at 838
passed."

**NIT  docs/architecture/mirror-supersedes-the-wrapper.md:61,69 — "Considered"
still says "the seven wrappers" twice.** The commit corrected the same stale
count in Context and in the older-Claude-Code paragraph (L33). Considered records
alternatives as weighed at decision time, so leaving it is defensible — but
fixing two of four instances is the inconsistency, not the count itself.
→ Fix: either leave all of Considered as of-its-time, or say "the seven wrappers
that then existed."
